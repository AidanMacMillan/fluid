# Fluid 0.1.3

## What's new

- Work with Codex alongside Claude Code, with shared agent controls and inline
  interactive visualizations. Agent message previews now omit embedded rich content.
- Search persistent task history and reopen saved pages, files, agent sessions,
  terminal directories, VS Code folders, and Slack threads. Matching open tabs are
  reused, and saved session names stay up to date.
- Write multiline searches and agent prompts in the launcher. Use Shift+Enter for
  a new line and Alt+Up/Down to move between results while editing.
- Resize the sidebar to a compact icon rail, reveal labels and controls in hover
  cards, and drag items between folders and pinned sections. Collapsed sidebars
  also peek over the current page without resizing it.
- Adjust interface density and transparency in Appearance settings, with improved
  native scrolling, fullscreen layouts, and video miniplayer focus.
- Improve Codex icon contrast and prepare terminal helpers before development and
  preview startup.

## For extension developers

- Restore saved visits with optional history callbacks and explicitly retained
  destination fields, including in sandboxed extensions.
- Opt launcher and new-task rows into multiline input with
  `supportsMultiline: true`. The field is optional and defaults to `false`, so
  existing entries keep their single-line behavior without changes.

## Install or update

- **Apple Silicon (M1 or newer):** download `Fluid-0.1.3-arm64.dmg`.
- **Intel Mac:** download `Fluid-0.1.3-x64.dmg`.

Open the DMG and drag Fluid into Applications. Existing signed installations
can update through **Fluid → Check for Updates…** once this release is published.
Fluid also checks for updates automatically in the background.

This is an early development release.
