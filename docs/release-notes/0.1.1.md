# Fluid 0.1.1

## What's new

- Block ads and known trackers in browser tabs, including private browsing.
  Settings → Privacy has independent switches and site exceptions that also
  cover subdomains. Ad blocking is on by default; tracker blocking is opt-in.
  Bundled filter lists work offline and refresh automatically when online.
- Use playback controls, captions, and proportional resizing in the video
  miniplayer. Its dismiss control now uses a minus icon.
- Mute browser tabs and use the page context menu for browsing tools.
- Enjoy refreshed dock icons with bevels and highlights, and a fix that keeps
  hovering from reopening the sidebar dock while it closes.
- Find desktop development and extension authoring guides in each package.
  Fluid is now licensed under MIT; third-party licenses still apply.

Reload open pages after changing ad or tracker blocking settings.

## Install or update

- **Apple Silicon (M1 or newer):** download `Fluid-0.1.1-arm64.dmg`.
- **Intel Mac:** download `Fluid-0.1.1-x64.dmg`.

Open the DMG and drag Fluid into Applications. Existing signed installations
can update through **Fluid → Check for Updates…** once this release is published.
Fluid also checks for updates automatically in the background.

This is an early development release.
