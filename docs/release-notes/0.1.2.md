# Fluid 0.1.2

## What's new

- Choose which side of the window the sidebar appears on in Settings → Appearance.
- Feel trackpad haptic feedback while dragging, with improved sidebar drop targets.
- Edit browser addresses with natural cursor placement and text selection. Full
  URLs remain visible, and submitted addresses stay in place while navigation starts.
- Open a new tab when following a link to the currently active pinned tab.
  Links to other pinned tabs still reuse their existing rows.
- Enjoy rounder, better-sized Dock icons with brighter edge highlights across all themes.
- Restore the main window reliably from the Dock, and keep Fluid visible in the
  Dock while using video miniplayers.
- Improve settings navigation, simplify the clipboard panel, and fix terminal
  startup in packaged macOS builds.

## Install or update

- **Apple Silicon (M1 or newer):** download `Fluid-0.1.2-arm64.dmg`.
- **Intel Mac:** download `Fluid-0.1.2-x64.dmg`.

Open the DMG and drag Fluid into Applications. Existing signed installations
can update through **Fluid → Check for Updates…** once this release is published.
Fluid also checks for updates automatically in the background.

This is an early development release.
