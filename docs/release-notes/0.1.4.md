# Fluid 0.1.4

## What's new

- Make Fluid your default browser, and choose your search engine for the
  launcher and new tabs.
- Pin tasks to the task strip and drag them between the pinned and unpinned
  sections. Pinned tabs now stay on their site.
- Find what you want faster: launcher rows are ranked by how well they match
  what you typed, and the new task panel offers the same rows as new tab.
- Pinch to zoom in browser tabs, mute a tab from its context menu, and keep the
  mute control visible for a few seconds after a tab stops playing sound.
- Toggle the compact sidebar from its resize handle, and see keyboard shortcuts
  in a bar on floating panels.
- Tasks and tabs scale down slightly while pressed.
- Browser tabs now send a Chrome user agent, which improves compatibility with
  sites that block unfamiliar browsers.

## Fixes

- Lists no longer rubber-band sideways when scrolling.
- The sidebar drop line appears only where a drop would actually land, and the
  pinned section's drop zone spans its title.
- A task's activity dot keeps a consistent size and steps aside on hover, and a
  tab's dot stays visible beside the close button.
- A task or tab stays highlighted while you hover its close button.
- The floating sidebar stays open after you release a resize, and its padding is
  balanced on both sides.
- The keyboard highlight is preserved under a stationary pointer.
- Closed tabs no longer publish stale state.

## Install or update

- **Apple Silicon (M1 or newer):** download `Fluid-0.1.4-arm64.dmg`.
- **Intel Mac:** download `Fluid-0.1.4-x64.dmg`.

Open the DMG and drag Fluid into Applications. Existing signed installations
can update through **Fluid → Check for Updates…** once this release is published.
Fluid also checks for updates automatically in the background.

This is an early development release.
